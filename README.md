## 📖 Overview

**Elkaif** is a landing page for a coffee shop that showcases its services and products and invites visitors to sign up. It was built as a front-end practice project focusing on layout, styling, and interactive UI effects using only HTML and CSS.

## ✨ Features

- **Fixed navigation bar** with logo, section links (Home, Services, Contact) and a "Join Us!" call-to-action
- **Product cards** (Espresso, Roasted Beans, Pastry) with images, descriptions, prices and "Order now" buttons
- **Flip-card authentication page** — a CSS-only toggle that flips between **Log in** and **Sign up** forms
- **Smooth transitions & fade-in effects** on cards, buttons and sections
- **Responsive layout** using Flexbox and media queries (mobile breakpoint at `768px`)
- **Footer** with social media links (Facebook, Twitter, WhatsApp)

## 🚀 Getting Started

No build step or dependencies are required.

```bash
# Clone the repository
git clone https://github.com/Mrawan-Nabil/my-coffeshop.git
cd my-coffeshop

# Open the site in your browser
start coffeshop.html      # Windows
open coffeshop.html       # macOS
xdg-open coffeshop.html   # Linux
```

Or use the **Live Server** extension in VS Code for auto-reload while editing.
